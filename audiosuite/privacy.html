Privacy Policy

TNKSND Audio Suite · Version 1.0

TNKSND Audio Suite does not collect any data. There is no account, no sign-in, no analytics, no advertising, and no third-party SDK that tracks you.

Microphone

The microphone is used only for live measurement (real-time analyzer, FFT analyzer, SPL meter). Audio is processed on the device to produce levels and spectra. Version 1.0 does not record, store, or upload microphone audio anywhere.

Files

The WAV analyzer reads only audio files you select. It does not access any other files on the device.

Network

No network connection is required for any version 1.0 tool. The app makes no network requests.

Calibration and settings

The calibration offset and microphone correction files you set are stored only on your device.

Changes to this policy

If a future version changes how data is handled, this page will be updated before that version is released.

Contact

Questions about this policy: support@tnksnd.com
