TNKSND Audio Suite · Version 1.0 · iPhone, iOS 17 or later

Four measurement tools in one app, with one calibration: an Nth-octave real-time analyzer (1 to 1/12 octave), a high-resolution FFT analyzer, an SPL meter with logging, and a WAV file analyzer.

Contact

For help, bug reports, or feature requests, email support@tnksnd.com. Please include your iPhone model, iOS version, the app version (shown on the About screen under More), and what you were measuring.

Calibration

SPL is calculated as dB SPL = dBFS + calibration offset. The default offset is +113.81 dB. Calibrate with an acoustic calibrator before relying on absolute levels. With the built-in microphone, levels are approximate and are labelled as such. This app is a measurement aid, not a certified sound level meter.

Common issues

  • No microphone input: the app asks for microphone permission the first time you open RTA, FFT, or SPL. If you declined, enable it in iOS Settings > TNKSND Audio Suite > Microphone.
  • Values labelled uncalibrated: the app shows live values as uncalibrated until you run the calibrator flow (More > Calibrator). This is expected.
  • WAV analyzer cannot open a file: it reads only files you select through the file picker. Files from other apps must be shared or saved where the picker can reach them.
